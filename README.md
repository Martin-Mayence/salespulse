# SalesPulse

SalesPulse is a sales analytics project built with Python
and PostgreSQL.

The application imports sales data from CSV files, validates
the data, stores it in a relational database and provides
business insights through SQL queries and an interactive
dashboard.

## Objectives

- Import and validate CSV sales data
- Store products, categories and sales in PostgreSQL
- Prevent duplicate sales during data imports
- Analyse revenue and sales performance using SQL
- Visualize key business indicators

## Tech stack

- Python
- PostgreSQL
- Psycopg 3
- Pandas
- Streamlit
- pytest
